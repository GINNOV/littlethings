A collection of tools and projects that I have built for the Amiga community. They aim to support Amiga developers and users in their daily tasks.

ADF.inder

There are many ADF tools out there but they almost feel to me that the author got a phone call for an important meeting and decided to not go back to finish what they started. I wanted an Opus File Manager for macOS users to handle Amiga disks. So I built it and when I got the call, I told to my non existing secretary "no calls today, I am coding".


ADF.inder allows you to operate on Amiga Disk images like there's no tomorrow. You can add/remove files, edit content, create images, I mean I haven't found a limitation yet. Click the Details button to see the current list of features.

PixDeluxe

Say that you have a large collection of Amiga images and you want to easily browse them, or you want to convert them to a different format, or snop meta details, or you want to apply a filter to them. You probably got the point.

Well...well, my dear fellow Amiganian. PixDeluxe is here to save the day. It opens IFF images, it can convert them to PNG, show image format details and more.

There has been a plugin around for about 12 years now but it doesn't work reliably anymore. So I brought it back to life. Download, move the app inside your Applications folder and then run it once. The rest will be history.

AuDeluxe

I enjoy listening to Amiga audio files while I code. I have a collection of Amiga audio files and I wanted a player that can handle all of them. I tried some players but they didn't have the macOS ethos I was looking for.

I wanted a modern player that can handle all Amiga audio formats and that can be used as a Quick Look plugin as well. So I built AuDeluxe. It supports all formats exposed by OpenMPT. Happy listening!

Amiga Playground

Amiga Playground is a native macOS workspace for writing, generating, assembling, and testing Commodore Amiga 68k code. It brings the editor, assistant, compiler console, ADF export, and emulator launch paths into one place.

The assistant generates Motorola 68000 assembly with a local Apple Silicon MLX model — Amiga Playground ASM (140/140 first-shot compile on the sealed harness). Ask for a copper list, assemble it, export a disk, and run it in FS-UAE, vAmiga, or the embedded web emulator.

Amiga ROM Explorer

Kickstart revisions, boot ROMs, extended ROMs, and cartridge firmware all have stories — which machine they belong to, what changed between revisions, and which dump quality matters for emulation. I wanted a native macOS atlas for that firmware history, not another folder of cryptic filenames.

Amiga ROM Explorer ships a bundled reference catalog with researched profiles for 125+ entries. Browse immediately in reference mode, or point it at your own legally obtained ROM library to match files, checksums, and hardware targets. Sparkle keeps updates flowing.

send to ADF

Quite often I find myself to test out a demo that I baked from source code. It's never just one file, add resources, a startup sequence and so on. Often I do those things from command line, including opening the file in vAmiga. I know about xdftool but I wanted something more independent that the whole amitools package.

send2adf, it's a C based tool that you can keep in your /usr/local/bin folder, no fancy installations. Straight from terminal you add a file or an entire folder structure in one shot to a dynamically created ADF file.

Amiga Login Screen

I saw this discussion on r/amiga so I figured let's make this accessible to a wider audience and for free. 12 euros for an app that leverages what ships with the mac sounded too much, so I built a macOS Droplet and command-line utility that formats and sets classic Commodore Amiga boot screens (or any custom image / animated GIF) as your Mac desktop wallpaper and lock screen.

Drag and drop any image onto the app icon for instant 1:1 sharp pixel scaling, or double-click to choose built-in presets: Kickstart 1.3 (hand holding disk), Kickstart 2.04, or Kickstart 3.1. Automatically samples background edge colors (e.g. Amiga Blue) to pad widescreen monitors cleanly. Native Universal Binary (Apple Silicon + Intel).

Removing macOS Quarantine

macOS may quarantine the app the first time you open it. If you give money to Apple, you can remove the quarantine but for free you can just use the instructions below.

Using Terminal

  1. Move the downloaded app into your Applications folder.
  2. Open Terminal and run this command, replacing the path if needed:
xattr -dr com.apple.quarantine "/Applications/PixDeluxe.app"

You can also drag the app from Finder into the Terminal window to insert its exact path, then press Return. Open the app again normally.

Using Sentinel

  1. Download Sentinel from its GitHub page.
  2. Drag the app you want to open onto Sentinel.
  3. Choose Unquarantine, then open the app normally.

Use Sentinel's Unquarantine action only. Do not use its self-sign action.
