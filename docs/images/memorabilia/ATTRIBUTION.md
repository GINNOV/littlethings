# Hardware photo attributions

Images in this folder are used by [Amiga ROM Explorer](https://github.com/littlethings/AmigaROMExplorer) for hardware model thumbnails. Sources are public museum/archive photographs from [Wikimedia Commons](https://commons.wikimedia.org/) unless noted.

Personal collection photos (`amiga_500_front.jpg`, `amiga_1200_front.jpg`, `amiga_1200_back.jpg`) are original photographs and are not redistributed under an open license.
