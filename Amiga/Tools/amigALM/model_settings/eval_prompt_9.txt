### INSTRUCTION ###
Generate a highly efficient, relocatable Amiga assembly subroutine to perform the following task.

### TASK ###
create_simple_copper_list

### SPECIFICATION ###
- **Inputs**: A0 should point to a memory region where the Copper list will be written.
- **Outputs**: A0 should point to the address immediately after the last instruction in the generated Copper list.
- **Register Preservation**: All registers from D3-D7 and A2-A6 MUST be preserved.
- **Scratch Registers**: D0, D1, D2, A0, and A1 can be freely used.
- **AmigaOS Calls**: None.
- **Format**: The routine must write a valid Copper list that sets COLOR00 to black, waits for scanline $50, sets COLOR00 to blue, and then ends the list. It should then return with RTS.
- **Comments**: Explain the structure of the Copper's MOVE and WAIT instructions.
