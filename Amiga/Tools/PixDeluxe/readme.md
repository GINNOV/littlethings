# PixDeluxe

it's a tool for macOS that loads and displays [IFF Amiga files](https://amitopia.com/new-jpeg-and-iff-datatypes-improves-speed-a-lot/) files. It also converts to PNG and offer other small useful utilties for the IFF journey.

I didn't find one for native macOS so I built it because I needed it as plug in for [ADFider](https://ginnov.github.io/littlethings/) to allow those users to quick preview IFF files inside Amiga Disk Images.

[Credit image](https://amitopia.com/new-jpeg-and-iff-datatypes-improves-speed-a-lot/) for the app icon.
Backend library lovely offered by [Svanderburg](https://github.com/svanderburg/libiff/tree/master) and contribs 🙏🏼

Enjoy
