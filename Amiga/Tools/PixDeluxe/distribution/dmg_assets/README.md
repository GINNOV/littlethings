# First installation

PixDeluxe is not notarized with Apple, so macOS may identify it as being from
an unknown developer. Use one of these free options for the first installation.

**Graphical:** Download the official open-source
[Sentinel](https://github.com/alienator88/Sentinel) app, drag PixDeluxe onto
it, and choose **Unquarantine**. Do not use Sentinel's self-sign action.

**Terminal:** After copying PixDeluxe to Applications, run:

`xattr -rc "/Applications/PixDeluxe.app"`

Build 112 is a one-time manual bridge release. Once it is installed, future
correctly signed updates can be installed through **Check for Updates**.

Enjoy.
