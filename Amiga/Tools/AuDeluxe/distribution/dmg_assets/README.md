# Quarantine Flag
AuDeluxe is not notarized with Apple, so macOS may identify it as being from an unknown developer. Use one of these free options for the first installation.

**Terminal**:
After copying AuDeluxe to Applications, run `xattr -rc /Applications/AuDeluxe.app`.

**GUI**:
Drag AuDeluxe onto [Sentinel](https://github.com/alienator88/Sentinel) and use its **Unquarantine** option. Do not use the self-sign option.

Build 79 is a one-time manual update that completes the sandboxed Sparkle setup. Once build 79 is installed, AuDeluxe can install future EdDSA-signed updates through **Check for Updates**.

Enjoy.
