### INSTRUCTION ###
Generate a highly efficient, relocatable Amiga assembly subroutine to perform the following task.

### TASK ###
unsigned_16bit_integer_division

### SPECIFICATION ###
- **Inputs**: D0.w should contain the dividend. D1.w should contain the divisor.
- **Outputs**: D0.w should contain the quotient. D1.w should contain the remainder.
- **Register Preservation**: All registers from D3-D7 and A2-A6 MUST be preserved.
- **Scratch Registers**: D0, D1, D2, A0, A1 can be freely used.
- **AmigaOS Calls**: None. This must be a pure mathematical routine.
- **Format**: Standard subroutine ending with an RTS instruction.
- **Comments**: Explain the division algorithm used (e.g., subtractive or shift-based).
