Miga Credits

This page credits the major external code, libraries, fonts, and bundled visual assets used by Miga. It is intentionally about direct project inputs and shipped art, not every transitive package inside node_modules/ or the Python environment. Return to the live dashboard

1. Core Project Lineage

  • karpathy/autoresearch: the fixed-time autonomous experiment-loop idea and program.md-driven workflow.
  • Apple MLX: the Apple Silicon ML runtime used by the training side of this repo.
  • scasella/nanochat-mlx: MLX GPT and optimizer reference material used while shaping the training code.
  • awni/picochat: MLX training-loop patterns referenced by the project.
  • OpenAI Responses API: optional mutator backend wired into amiga_copper_mutation_loop.py.

2. Runtime And Tooling

  • Express: serves the dashboard, docs pages, static files, and monitor API.
  • Playwright: drives Chromium for the browser-based Amiga evaluation flow.
  • vAmigaWeb: browser emulator frontend used by the Amiga evaluator.
  • vAmiga: upstream emulator project behind the vAmiga family used here.
  • vasm: 68k assembler used by the Amiga build and evaluation path.

3. Typography

  • Bricolage Grotesque: primary display and UI text face in the dashboard and docs.
  • IBM Plex Mono: monospace face for commands, file paths, and metric readouts.

These fonts are loaded from Google Fonts by the dashboard and docs pages.
