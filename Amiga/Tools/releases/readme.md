# Release notes

* Only the last three builds are kept on the repo per app/tool.
* If you pick the highest build number, you always have the latest release (doh...).
* Some functionalities, like Shortcuts integration, are only possible with a signed build. That means if you have an Apple Developer paid account, you can generate it yourself; otherwise, you won't have that functionality. I will eventually push a build on the App Store to make it simpler for people.

Donations are always welcome 🤗
