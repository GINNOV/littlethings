# TOOLS
1️⃣ ADFinder - The Ultimate ADF Manager for macOS

2️⃣ send2Adf - Command line tool for creating on the fly ADF images

3️⃣ PixDeluxe - IFF manager (convert, browse, make coffee and so on)

4️⃣ ADF0 - Send2ADF on steroids

5️⃣ IFFViewer - A QuickLook plugin for Amiga images (IFF)

More details about those tools are [here](https://ginnov.github.io/littlethings/).

# Release notes

1. Only the last three builds are kept on the repo per app/tool.
2. If you pick the highest build number, you always have the latest release (doh...).
3. Most likely, you have to remove the tool from Apple Quarantine to run it for the first time. The instructions are inside the DMG. 
4. Some functionalities, like Shortcuts integration, are only possible with a signed build. That means if you have an Apple Developer paid account, you can generate it yourself; otherwise, you won't have that functionality until I get an app store account setup. I will eventually push an Amiga suite apps on the App Store to make it simpler for people.
