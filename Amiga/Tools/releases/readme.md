# Release notes

* Only the last three builds are kept on the repo per app/tool.
* If you pick the highest build number, you always have the latest release (doh...).
* Some functionalities, like Shortcuts integration, are only possible with a signed build. That means if you have an Apple Developer paid account, you can generate it yourself; otherwise, you won't have that functionality until I get an app store account setup. I will eventually push an Amiga suite apps on the App Store to make it simpler for people.
