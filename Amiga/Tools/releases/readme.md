# TOOLS
1️⃣ **ADFinder** - The Ultimate ADF Manager for macOS

2️⃣ **send2Adf** - Command line tool for creating on the fly ADF images

3️⃣ **PixDeluxe** - IFF manager (convert, browse, make coffee and so on)

4️⃣ **ADF0** - Send2ADF on steroids

5️⃣ **IFFViewer** - A QuickLook plugin for Amiga images (IFF)

6️⃣ **AuDeluxe** - Play all sorts of Amiga audio files (e.g. mods)

7️⃣ **AmigaPlayground** - macOS workspace for writing, assembling, MLX AI code generation, and testing Commodore Amiga 68k code

8️⃣ **AmigaROMExplorer** - Firmware and Kickstart ROM catalog & match utility

9️⃣ **AmigaLoginScreen** - macOS Droplet & CLI utility that formats and sets classic Amiga boot screens (Kickstart 1.3/2.04/3.1) as your desktop wallpaper and lock screen

More details and live demos for all tools are available on the [Amiga Dev Hub](https://ginnov.github.io/littlethings/amiga/index.html).

# Release notes

1. Only the last three builds are kept on the repo per app/tool.
2. If you pick the highest build number, you always have the latest release (doh...).
3. Most likely, you have to remove the tool from Apple Quarantine to run it for the first time. The instructions are inside the DMG or on the [Amiga Dev Hub Quarantine Guide](https://ginnov.github.io/littlethings/amiga/index.html#remove-quarantine).
4. Some functionalities, like Shortcuts integration, or QuickLook are only possible with a signed builds. That means if you have an Apple Developer paid account, you can generate it yourself; otherwise, you won't have that functionality until I get an app store account setup. I will eventually push an Amiga suite apps on the App Store to make it simpler for people.
