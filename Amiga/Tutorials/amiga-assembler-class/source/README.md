# Course source

This directory contains the maintained AsciiDoc source for the companion
learning path. The preserved book source remains in
`tmp/upstream-total-amiga-assembler`; the course-owned source here records the
new material that extends it.

The EPUB spine includes `modern-learning-path.adoc` before the preserved book
body. Rebuild the EPUB from the preserved checkout after copying this file into
its `asciidoc/` directory, or update the build checkout to use this source
directly.
