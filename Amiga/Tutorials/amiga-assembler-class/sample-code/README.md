# Sample code

This is the teaching copy of the source files preserved with *Total Amiga Assembler*.

The original repository layout is retained so examples can be located by chapter:

- `ChapterExamples/` contains the chapter-by-chapter assembler and C examples.
- `OtherExamples/` contains the Intuition, data-type, and smooth-scrolling examples.
- The files at this level are the original project notes and assembler guidance.

Only readable source and documentation are copied here. Compiled Amiga executables,
object files, linker outputs, and icon files remain in the preserved checkout at
`tmp/upstream-total-amiga-assembler/src` rather than being mixed into the teaching
source tree.

The material is credited in the course-level [README](../README.md). This folder is
an expanded, learner-friendly working copy; it does not replace the preserved source.
