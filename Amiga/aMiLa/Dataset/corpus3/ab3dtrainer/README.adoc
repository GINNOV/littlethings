# AB3DTrainer 

**Description**: Patch program for Alien Breed 3D

A patch program for "Alien Breed 3D" from Team 17. It supports:

        * Floppy AB3D as distributed by Team 17
        * Patched AB3D with 8-channel stero sound added, available from
        the Team 17 ftp site ftp2.team17.com and Aminet.
        * CD32 version

Also compatible with HackAB3D.

Provides:
    
    - infinite energy
    - infinite ammunition for all weapons (once collected).
    - joypad/joystick compatibility patch

Does not modify your game executable on disk. Does not require you to decrunch your Alien Breed 3D executable.

**Technology stack**: C, 68k, SAS/C 6.5x, Devpac

**Project Status**:  https://gitlab.com/amigasourcecodepreservation/ab3dtrainer/blob/master/CHANGELOG.adoc[CHANGELOG]


## Dependencies

  * Amiga OS Classic
  * NDK3.9 with https://gitlab.com/amigasourcecodepreservation/complete-ndk39[complete] assembler updates (only tested with)
  * SAS/C 6.5x or compatible C-compiler
  * Devpac or compatible assembler compiler
  * http://aminet.net/package/util/cli/DoVer[DoVer]
  * https://gitlab.com/amigasourcecodepreservation/buildtime[BuildTime]
  * https://gitlab.com/amigasourcecodepreservation/cgle[cgle] 
  * https://gitlab.com/amigasourcecodepreservation/newstartup[NewStartup]
  

## Installation

To build: First smake under the src/gui folder. Then build the AB3DTBoot.s with Devpac and put it in the same folder as gui-output.
