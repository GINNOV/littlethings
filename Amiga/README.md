# Amiga

If it were not for the Commodore Amiga, I would have never started the career that shaped my future and self-growth. Decades later, this folder is where I collect the tools, source archives, tutorials, and notes from that flashback journey.

The friendlier website version is here: <https://ginnov.github.io/littlethings/>.

## Start Here

| Folder | Purpose |
| --- | --- |
| `Tools/` | macOS and Amiga utilities, plus release builds when available. |
| `aMiLa/amiga_sources/` | LLM-oriented Amiga source corpus. Start with `aMiLa/amiga_sources/README.md` and `_catalog/` for the index. |
| `aMiLa/fine_tuning/fused_model/` | Fine-tuned Antigravity Amiga 68k model output and [model card](aMiLa/fine_tuning/fused_model/README.md). |
| `Tutorials/` | Notes and walkthroughs from experiments and learning sessions. |
| `setup_env/` | Environment setup material used by some Amiga workflows. |

## What To Expect

- `Tools/` is the best starting point if you want to run something.
- `aMiLa/` contains the native Amiga Playground app, model tooling, and source corpus work.
- The fine-tuned model is documented in the [Antigravity Amiga 68k model card](aMiLa/fine_tuning/fused_model/README.md).
- Some tools are tested in FS-UAE, vAmiga, or on real Amiga hardware, depending on the project.
